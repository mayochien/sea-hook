# 🎣 Sea Hook 大海上鉤

一個以「邊玩邊懂海」為主題的作品展示網站——把台灣海況、潮汐資料變成一眼看懂的地圖與圖表，
再用一個手刻的 SVG 海釣小遊戲，把「什麼樣的浪況適合出海」這件事變得直覺又有趣。

## 這個作品想展示什麼

- **串接真實政府開放資料**：直接呼叫中央氣象署（CWA）開放資料平台的浪高、潮汐 API，
  並在資料不足或請求失敗時，自動退回內建的假資料，確保畫面永遠有東西可看。
- **手刻 SVG 動畫與遊戲邏輯**：海況地圖、潮汐曲線、海釣小遊戲的船隻／人物／魚竿／魚群，
  全部是純手刻的 SVG 路徑與 `animate`／`animateTransform` 動畫，沒有用任何美術素材或遊戲引擎。
- **狀態管理與元件拆分**：用 [zustand](https://github.com/pmndrs/zustand) 集中管理海況資料，
  搭配 selector 讓各元件只訂閱自己需要的狀態，避免 props 一路往下傳。
- **中文使用者體驗設計**：從措辭、資訊層級到互動回饋，都是以中文使用者的閱讀習慣去設計版面。

## 功能亮點

1. **台灣海況地圖**：點選北／西／東／南部海域，即可切換浪高、潮差、下一次滿潮／低潮等資訊。
2. **潮汐示意圖**：依當天各時段的潮高資料繪製曲線，並標示目前時間、滿潮與低潮位置。
3. **海釣互動小遊戲**：下竿後等待魚竿尾端晃動再起竿，浪況越大、魚也越容易脫鉤——
   遊戲機制直接反映真實海況資料，而不只是裝飾動畫。
4. **常見魚種圖鑑**：整理臺灣沿海常見魚種與《臺灣海鮮選擇指南》的資料，附搜尋與分頁功能。
5. **魚種知識小測驗**：隨機出題、即時對答案，用輕鬆的方式認識台灣魚類生態。

## 技術棧

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- [Zustand](https://github.com/pmndrs/zustand) 做全域狀態管理
- [Tailwind CSS 4](https://tailwindcss.com/) 做版面樣式
- [中央氣象署開放資料平台](https://opendata.cwa.gov.tw/index)：浪高（O-B0075-001）、潮汐（F-A0021-001）
- [臺灣魚類資料庫](https://fishdb.sinica.edu.tw/) 與 [臺灣海鮮選擇指南](https://fishdb.sinica.edu.tw/seafoodguide/)：魚種圖鑑資料來源

## 在本機執行

```bash
npm install
npm run dev
```

海況資料需要中央氣象署的 API 金鑰，可在 [開放資料平台](https://opendata.cwa.gov.tw/index) 免費申請後，
填入專案根目錄的 `.env`：

```bash
VITE_CWA_API_KEY=你的金鑰
```

沒有金鑰或請求失敗時，畫面會自動改用內建的假資料展示，不影響操作體驗。

## 專案結構

```
src/
  components/   # 海況地圖、潮汐面板、海釣遊戲、魚種圖鑑、知識測驗等畫面元件
  store/        # zustand 全域狀態（海況 dashboard、選取的海域）
  data/         # 魚種圖鑑、測驗題庫、浪況分級說明等靜態資料
  lib/          # 呼叫中央氣象署開放資料 API 並整理成畫面可用的格式
  types/        # 跨元件共用的型別定義
```
